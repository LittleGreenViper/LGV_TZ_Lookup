Detailed Description

All parser events reach the package unchanged. When a Feature object closes, the loader's GeoJSON listener exposes that decoded Feature through getJson(). We retain its compact reference geometry before the next Feature replaces it. We do not build a second nested copy of the entire GeoJSON document.
