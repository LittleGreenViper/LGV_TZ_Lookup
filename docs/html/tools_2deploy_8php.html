deploy.sh supplies a private working directory. The worker asks for settings through the terminal, installs the Composer package, loads current boundaries, and checks known locations before publishing a small endpoint. A separate cleanup process removes downloads and rolls back an incomplete installation after errors or OOM. Database ownership is verified with a random guard token before cleanup can remove a newly loaded table.
