Run with –driver=mysql or –driver=pgsql. Connection overrides use LGV_TZ_TEST_HOST, PORT, USER, PASSWORD, and ADMIN_DATABASE. The tests create their own uniquely named database and remove it in a finally block. They check loading, binary encoding, lookup precedence, bounded row fetching, cursor cleanup, and transaction ownership. –autoload=/path/to/vendor/autoload.php runs the same checks against a Composer consumer installation.
