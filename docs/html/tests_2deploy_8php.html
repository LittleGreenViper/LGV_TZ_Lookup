These tests check deployment ownership and recovery against an isolated MySQL or PostgreSQL database. Run with –driver=mysql or –driver=pgsql, using the same LGV_TZ_TEST_* settings as tests/databases.php. No boundaries are downloaded. The test database and working directories are removed afterward.
