◆ preparedRows()

LGV_TZ_Lookup_PDO::preparedRows ( $sql,
$params = array(),
$buffered = true )

Yield rows one at a time and release the cursor, including when a lookup returns before consuming every row. Polygon reads can disable MySQL buffering to avoid retaining every candidate blob. An unbuffered reader must be closed before another query; the finally block drains its cursor and restores the connection mode. PostgreSQL uses single-row fetching on PHP 8.5+, or a server cursor on earlier PHP releases. BYTEA streams are read and closed here, so callers receive the same binary strings on either database.
